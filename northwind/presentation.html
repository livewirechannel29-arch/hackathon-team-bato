The Problem

The Code

The People

The developer who built it left in 2011. The manager who greenlit it retired in 2019.

The Ask

The board approved "modernization" without defining what that means. Orders are still going out every day.

Why Not Rewrite?

The Big-Bang Trap

"We'll rewrite it properly over six months, then cut over on a weekend."

What Goes Wrong

  • 🔴  The cut-over weekend turns into three
  • 🔴  Edge cases only production traffic reveals
  • 🔴  Feature freeze during the rewrite
  • 🔴  Rewrite inherits the same design mistakes
  • 🔴  Team burns out; project gets cancelled

What We Do Instead

  • ✅  Legacy stays running throughout
  • ✅  Extract one route at a time
  • ✅  Same database — no migration
  • ✅  Rollback = one config change
  • ✅  Ship features while migrating

The Legacy Monolith

The Smell: String-Concatenated SQL

# legacy_server.py — the PHP 5 sins, faithfully ported

def sql_concat_query(status_filter, cid_filter):
    sql = """SELECT o.order_id, o.status, c.company_name ...
             FROM orders o JOIN customers c ... WHERE 1=1"""

    if status_filter:
        sql += f" AND o.status = '{status_filter}'"   # ← injection
    if cid_filter:
        sql += f" AND o.customer_id = {cid_filter}"    # ← injection

    return sql

# auth check — same pattern
sql = f"SELECT * FROM employees WHERE username='{username}' AND password='{password}'"
emp = con.execute(sql).fetchone()   # admin'-- logs in as anyone

This is running live at localhost:8081 — every query, every login, exactly this.

The Modern Service

The Fix: Prepared Statements

// modern/server.js — same query, same database, no injection

const OrderRepository = {
  list(status = '', customerId = 0) {
    const conditions = ['1=1'];
    const params     = {};

    if (status)       { conditions.push('o.status = $status');          params.$status     = status; }
    if (customerId) { conditions.push('o.customer_id = $customerId'); params.$customerId = customerId; }

    const sql = `SELECT ... WHERE ${conditions.join(' AND ')} ...`;
    return db.prepare(sql).all(params);  // ← named parameters, no injection
  }
};

// GET /api/orders?status=pending
app.get('/api/orders', (req, res) => {
  const orders = OrderRepository.list(req.query.status, req.query.customer_id);
  res.json({ data: orders, count: orders.length });
});

Serving at localhost:8082 — same rows, same database, no injection surface.

The Control Plane

Migrate a Route in One Line

// proxy/proxy.js — the migration control plane

const MODERN_ROUTES = [
  /^\/api\/orders(\/|$)/,           // ✅ extracted — routes to modern app

  // /^\/api\/customers(\/|$)/,       // uncomment when ready
  // /^\/api\/products(\/|$)/,        // uncomment when ready
  // /^\/api\/reports(\/|$)/,         // uncomment when ready
];

const target = MODERN_ROUTES.some(re => re.test(req.url))
  ? MODERN   // → http://localhost:8082
  : LEGACY;  // → http://localhost:8081  (untouched)

proxy.web(req, res, { target });

The legacy server never knows it's being replaced. Rollback = comment out the line.
